# Interface steering

Use a calm modular grid: off-white surface, ink text, teal accent, accessible status chips, restrained borders and consistent spacing. Patient flow is linear; doctor workspace uses clear independent panels. Source drawer and before/after comparison are primary interactions. Avoid decorative clinical scores, diagnosis probability, treatment recommendation controls and fabricated metrics. Show loading, no-match, missing information, conflict, offline, synthetic mode and failed validation explicitly. Keyboard access and readable phone layout matter more than animation. See `docs/06-ui-and-demo.md`.
