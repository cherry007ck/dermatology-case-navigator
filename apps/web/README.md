# Web app (Luffy)

Next.js App Router + TypeScript + Tailwind + shadcn/ui. Run commands, environment variables and
modes are documented in the repository root `README.md`.

- `lib/api/generated.ts` is generated from `contracts/openapi.json` (`npm run generate:api`). Do not edit.
- `mocks/fixtures/` is copied from `contracts/examples` (`npm run sync:fixtures`). Do not edit.
- `AGENTS.md` here is written by Next.js itself; the repository root `AGENTS.md` is the team rulebook.
