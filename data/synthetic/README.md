# Fictional fixtures only

These three case records and two patient scenarios were authored for software demonstration. They are not published evidence, medical advice, clinically representative data or clinically validated comparison examples.

- `cases.json`: fictional narratives, explicit features, passage references and neutral documentation actions.
- `collection.json`: collection metadata and deterministic content hash.
- `scenarios.json`: ordinary patient statements and expected mechanical ranking changes.
- `../../contracts/examples/`: serialized snapshots and voice-tool output, intended for shared frontend/backend mocks.

`fixture_checked` means quote/ID consistency verified by the pack validator; it does not mean clinical review. The fixture timestamps are deterministic demonstration timestamps. Use a separate collection for real sources; never rename these records to make them appear published.

The no-match scenario has scalp discomfort while the scalp case explicitly describes burning. The limited alias map does not equate these symptoms, so no case qualifies. That is a property of the demonstration collection/rules, not a medical conclusion.
